# Guía de decisión · SK00

## Entrada de ejemplo

Retomamos un agente del que solo hay un README viejo que dice listo, un test reciente fallido y un presupuesto estimado. La demo es mañana. Prepara el contexto para continuar sin volver a investigar todo.

## Qué debe resolver

Distinguir hechos/historia/hipótesis; reutilizar evidencia; presupuesto estimado no autorización; siguiente paso acotado.

## Opciones

- Reutilizar inventario verificado
- Inspección acotada del repo
- Entrevista breve para un bloqueo real
- Investigación nueva solo para una brecha o dato cambiante

## Contrato de salida

contexto.md: objetivo, fuentes, matriz de evidencia, decisiones vigentes, contradicciones, pendientes y siguiente paso verificable.

No todas las opciones deben implementarse. Compara al menos la opción sencilla viable y la alternativa que resolvería su limitación. Declara supuesto, evidencia, coste de cambio y señal para reconsiderar.
